## OpenClaw 설치

이제 본격적으로 OpenClaw를 설치해보자

우선 OpenClaw를 설치하기 위해 필요한 패키지들이 있다.
```bash
dnf install -y git tar gzip dnf-utils policycoreutils-python-utils
dnf groupinstall -y "Development Tools"
dnf install -y cmake gcc-c++ python3
```
그리고 가장 중요한 node.js 설치가 필요하다.

1. 기존 설치 여부 확인 및 패키지 정리

우선 기존 패키지에 node.js가 설치된 상태인지 확인을 진행하고,
이미 설치된 상태라면 충돌 방지를 위해 기존 node.js를 삭제한다.
```bash
#설치 여부 확인
node -v
rpm -q nodejs

#설치된 상태라면 삭제 진행
sudo dnf remove -y nodejs
```

2. Node.js 22 설치

공식 배포 저장소를 등록하여 다운로드를 진행한다.
```bash
curl -fsSL https://rpm.nodesource.com/setup_22.x | sudo bash -
```
![배포 저장소 등록](./imges/post_260202_2/img01.png)

이제 node.js를 설치한다.
```bash
sudo dnf install -y nodejs
```
![nodejs 설치](./imges/post_260202_2/img02.png)


3. OpenClaw 설치

Node.js 22 버전이 설치됐다면 이제 본격적으로 OpenClaw 설치를 진행한다.

아래 명령어로 openclaw 설치를 진행한다.
```bash
curl -fsSL https://openclaw.ai/install.sh | sudo bash
```
![openclaw 설치](./imges/post_260202_2/img03.png)

4. 실행

아래 명령어로 openclaw 실행이 가능하다.
```bash
openclaw gateway
```

만일 서버와 접속하는 환경이 다르다면, 하기 항목을 수정해야 된다.
```bash
vi ~/.openclaw/openclaw.json
```

```bash
 22     },
 23     "port": 18789,
 24     "bind": "lan", #loopback을 lan으로 변경
 25     "tailscale": {
 26       "mode": "off",
 27       "resetOnExit": false
 28     }
```

이제 실행된 후 부가적인 설정이 필요하다.

아직 http로 접근 시 발생하는 disconnected (1008): control ui requires HTTPS or localhost (secure context) 오류나,

api 설정 방법에 대해 확인이 필요하여 추후 진행 방법을 정리하여 포스트를 작성할 예정이다.
